# Агент заказа запчастей по VIN

Локальный помощник руководителя на Windows: голос → VIN и список деталей → подбор → дневной лот → оформление заказа (постоплата, без оплаты).

## Запуск

1. Python 3.11+ (на этой машине уже есть).
2. Дважды `run.bat` **или**:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

3. Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080) в Chrome / Edge (нужен микрофон).

`faster-whisper` тянет модель при первой расшифровке файла. Основной ввод — распознавание речи **в браузере** (удерживать «Говорить»).

## Настройки `.env`

| Переменная | Смысл |
|---|---|
| `LLM_PROVIDER` | `off` / `yandex` / `qwen` / `openai`. Подключение и отключение — [ПАМЯТКА-LLM.md](ПАМЯТКА-LLM.md) |
| `LLM_API_KEY` / `LLM_FOLDER_ID` | Ключ и каталог Yandex Cloud (или ключ OpenAI). Без ключа — только локальный разбор |
| `QWEN_API_KEY` / `QWEN_BASE_URL` / `QWEN_MODEL` | Qwen Cloud (DashScope). При `QWEN_FALLBACK=1` — запасной, если Yandex недоступен |
| `LLM_BASE_URL` / `LLM_MODEL` | Эндпоинт и модель основного провайдера |
| `LLM_NONSTANDARD_ONLY` | `1` — облако только на редкие формулировки (путь B) |
| `CITY` | Город получения, по умолчанию **Тюмень** |
| `SUPPLIER_ADAPTER` | `live` (все), `rossko`, `partkom`, `emex`, `exist`, `mock` |
| `ROSSKO_KEY1` / `ROSSKO_KEY2` | Ключи API Росско из кабинета (цены и наличие) |
| `ROSSKO_USER` / `ROSSKO_PASSWORD` | Вход на [tmn.rossko.ru](https://tmn.rossko.ru/) |
| `PARTKOM_USER` / `PARTKOM_PASSWORD` | B2B API / кабинет [part-kom.ru](https://part-kom.ru/) |
| `EMEX_USER` / `EMEX_PASSWORD` | Веб-сервис и кабинет [emex.ru](https://emex.ru/) (доступ с IP в ws.emex.ru) |
| `EXIST_USER` / `EXIST_PASSWORD` | Кабинет [exist.ru](https://www.exist.ru/), офис Тюмень |

Время лота по умолчанию **16:00** локального времени ПК, меняется в шапке.

Поставщики (получение — Тюмень):

- [Росско](https://tmn.rossko.ru/) — автозапчасти, OEM по VIN
- [ПартКом](https://part-kom.ru/) — автозапчасти, VIN-каталог, ПВЗ Малышева, 2А
- [Emex](https://emex.ru/) — автозапчасти, поиск по артикулу (SOAP при логине)
- [Exist](https://www.exist.ru/) — автозапчасти, каталог и офис в Тюмени

Без ключей кабинета агент всё равно формирует лот со ссылками на поиск; живые цены появятся после `ROSSKO_KEY*` / `PARTKOM_USER` / `EMEX_USER`. Оформление — Playwright, постоплата, без оплаты картой.

## Правила работы

- Обычные позиции копятся в лоте дня и уходят **одним заказом**.
- Пустой лот не отправляется.
- Срочные — сразу, вне лота.
- **Режим обучения** (вкл. по умолчанию): перед отправкой нужно подтверждение. Выключите, когда можно без кнопки.
- Оригинал только если сказано в заявке.
- В лот попадают позиции с одним сроком поставки.

Пока нет ключей кабинета, автозапчасти бронируются как черновик со ссылкой на поиск. Каркас Playwright открывает нужный кабинет в Тюмени.
